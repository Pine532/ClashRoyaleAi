# Values to look up

Units: engine level 11 for cards, level 9 for Crown Towers; 10 ticks = 1 s; ranges in tiles (attack surface-to-surface, sight centre-to-centre); speed as tier name (Slow / Medium / Fast / Very Fast); hp and damage at level 11. Ids in the Card column are engine card ids (negative = spawned helper unit). "First hit" = first-hit (load) time, the delay before a unit's first strike on a new target, in seconds on the game and stat sites.

Reply with: card, stat, value (level 11 / tiles / seconds), source URL (prefer an official Supercell post, else RoyaleAPI / DeckShop / wiki; say if single-source). Rows with no number (mechanic questions) want yes/no or a measured behaviour.

**Updated 2026-11-19** from `docs/live_sync/values-lookup-results.md`. Rows it settled were removed, and the values applied are recorded in `ledger.json` under `values_lookup_2026_11_19`. Rows it informed but did not settle were updated, and one new disagreement was added (Cannon damage).

**Updated 2026-11-20**: the Hero Ice Wizard Snowman was built (user-relayed RoyaleAPI developer-build write-up); its hp, spawn offset and radius left this list, and the two inferences (lifetime, Crown Tower damage) and the 10-27 refund window stay open.
